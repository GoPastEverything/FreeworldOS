# Contributing

FreeWorldOS is in early architectural recovery and bootstrap development.

Before contributing compatibility code:

1. Preserve the founding law: compatibility at the edges, originality inside.
2. Add public/documented sources to `docs/cleanroom/SOURCES.md`.
3. Describe observable interoperability behavior before implementation details.
4. Do not submit leaked, proprietary, copied, or disassembly-derived source code.
5. Keep image format, environment, ABI, and CPU architecture separate in new APIs.
